Supabase 연결

연결 대기

프로젝트의 공개 URL과 Publishable key를 설정한 후 SQL 설치 파일을 실행해 주세요.

kvm-config.js
supabaseUrl: 'https://PROJECT.supabase.co'
supabasePublishableKey: 'sb_publishable_…'

DB 설치: supabase-schema.sql
설정 안내: SUPABASE_SETUP.md

관리자 권한은 서버에서 별도로 부여합니다. 공개 페이지에서 권한을 변경할 수 없습니다.
